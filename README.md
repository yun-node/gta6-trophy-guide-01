Leonida Legend is an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5, with a saved checklist, a roadmap to the platinum, missable warnings, and a cited guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The guide is plain static files under `app/` — no build step, no network requests — so any static server works, and it keeps working with the network off. Tick trophies off to save progress in the browser; export and import it as a JSON file.
